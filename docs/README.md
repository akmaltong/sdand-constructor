# Sdand Constructor — документация

Web-конфигуратор для застройщиков выставочных стендов.

## Документы

- [SPEC.md](SPEC.md) — расшифровка рукописного ТЗ (4 фото)
- [ROADMAP.md](ROADMAP.md) — два этапа поставки с чек-листами
- [ESTIMATE.md](ESTIMATE.md) — ставки и бюджет
- [ARCHITECTURE.md](ARCHITECTURE.md) — структура репозитория и стек

## База

Стартуем на форке **Pascal Editor** (`editor-0.9.1.zip` распакован в корень репо).
Это open-source 3D-редактор зданий на React Three Fiber + WebGPU с готовыми
scene graph, стенами, зонами, коллизиями и undo/redo.
