# SPEC — Конфигуратор для застройщиков стендов (Web)

Расшифровка рукописного ТЗ (4 фото от 2026-08-05, `photo_2026-08-05_20-26-*.jpg`).

## 1. Продукт

Web-приложение для проектирования и расстановки выставочных стендов.
Пользователи — застройщики стендов и организаторы выставок.

## 2. Функциональные возможности

### 2.1 Зонирование и планировка
- Зонирование залов
- Расстановка стендов
- Компоновка и проектирование
- Планировка метража

### 2.2 Синхронизация
- Общий вид зала — все заказчики и их стенды в одной сцене
- Realtime-обновление при изменениях

### 2.3 3D-площадки (пресеты)
- XPO Forum
- Гостиный двор («Гостинка»)
- Расширяемый список

### 2.4 Работа с планом зала (метровая привязка)
- Пустая стена с разметкой (метровая сетка)
- Ручное рисование стен и зон
- Разметка метража визуально
- Два входа для плана:
  1. Заказчик присылает 2D-план — импортируем как подложку
  2. Заказчик рисует сам в 3D
- Разметка метровой привязки на полу

### 2.5 Библиотека 3D-моделей стендов
- Форматы: `gltf` / `obj`
- Наложение картинки (текстуры/брендинг)
- Модели заказчиков хранятся в общей библиотеке
- Размещение в сцене с поворотом кратно 45°

### 2.6 Правила размещения
- Коллизии: где занято — ставить нельзя
- Snap к сетке (метровая привязка)

### 2.7 Упрощённый конструктор
- Быстрый режим сборки стенда из готовых блоков
- Для заказчиков без 3D-опыта

### 2.8 AI-механики
- ИИ-генератор стендов по заданным размерам
- Нейронка для авто-обработки загружаемых моделей:
  - правит pivot
  - нормализует масштаб
  - автоматом заливает в базу

## 6. Открытые вопросы

Требуют уточнения у заказчика:
- Модель монетизации: SaaS-подписка или per-project?
- Кто владеет библиотекой моделей — организатор площадки или заказчик стенда?
- Нужна ли мультиплатформенность площадок (несколько выставочных центров одновременно)?
- Формат экспорта итогового проекта (PDF, gltf, DWG)?
- Роли и права: организатор, застройщик, заказчик, модератор моделей
- Хостинг: облако / on-premise?
